# Translation and right-to-left

Cairn is built to be translated and mirrored from the start, so no screen is written twice.

## What is decided

- **English first, nothing hard-coded.** The first release language is English. The design system never hard-codes a word a person reads or hears: every string it speaks by itself is in `UiStrings` (`packages/ui/src/i18n.tsx`) and replaced with `UiProvider`. Anything left out falls back to English, so a half-finished translation never shows a blank.
- **Screens own their own words.** Button text, headings and errors belong to the screen that shows them and will come from the app's message catalogue (chosen in Phase 2, with the app shell). The design system only owns screen-reader labels, like "Loading" and "Dismiss".
- **Right-to-left works without overrides.** CSS uses logical properties (`inset-inline-start`, `padding-inline-end`) and one direction variable, `--cairn-dir`. A test fails if a physical `left` or `right` is added without a reason written on the line. Arrows and chevrons mirror; icons like a magnifying glass do not.
- **The page sets its language and direction.** `lang` and `dir` go on the `<html>` element, using `directionOf(locale)`. Arabic, Hebrew, Persian, Urdu and a few others are right to left.
- **Mixed-direction text.** Anything a person or the agent wrote, such as a toast or a chat message, uses `dir="auto"` so each piece flows in its own script. Chat messages get this in Phase 4.

## What is not done yet

- The message catalogue library and plural, number, date and currency formatting. Currency matters from the first payment work.
- A pseudo-locale (long, accented text) to catch layouts that break when words are 40 percent longer. Planned with Storybook.
- Real translations. The Arabic strings on the demo page are samples to prove the layout. Every shipped translation needs a native speaker to review it. Twi (`tw`) and Ga (`gaa`) are candidates for early community translations given the home market.
- Fonts that cover Arabic, Hebrew, Devanagari, CJK and other scripts. The current font stack falls back to the system font for these.
- Menu and toast placement near the sides of the screen in right-to-left layouts, beyond the mirroring done here.
